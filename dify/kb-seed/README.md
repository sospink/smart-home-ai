# Dify 知识库种子文档

目录 `dify/kb-seed/` 用于存放可直接导入 Dify Dataset 的 Markdown 文档。

## 推荐导入顺序

1. `01_系统总览.md`
2. `02_系统架构与服务关系.md`
3. `03_核心功能与页面导航.md`
4. `04_设备控制与HomeAssistant映射.md`
5. `05_AI对话_知识库_智能体编排.md`
6. `06_API与数据模型速查.md`
7. `07_部署配置与运行边界.md`
8. `08_常见问题与FAQ.md`

## 这组文档适合回答的问题

- 平台是什么、怎么组成
- 哪个模块负责什么功能
- 聊天、知识库、设备控制分别依赖什么服务
- 当前 API 和数据模型有哪些
- 部署时需要哪些配置
- 常见报错和使用边界是什么

## 导入建议

- 文档类型：Markdown
- 切片策略：按默认段落切片即可
- 命中策略：优先语义检索
- 如果知识库中已有旧版“第一阶段”文档，建议删除旧文档后再导入本目录，避免回答口径冲突
