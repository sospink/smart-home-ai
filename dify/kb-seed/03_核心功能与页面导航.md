# 核心功能与页面导航

## 用户端页面

### `/home`
- 平台品牌首页
- 用于介绍系统定位、能力和整体场景

### `/chat`
- AI 对话主页面
- 支持流式返回、会话列表、历史消息、删除会话、停止响应
- 后端实际调用 Dify Chatflow API

### `/devices`
- 逻辑设备列表与状态展示
- 支持按分类查看设备
- 可显示场景、设备在线状态、类别统计

### `/sandbox`
- 电子沙盘 / 虚拟家居场景
- 用于展示设备注入、控制和可视化联动

### `/monitor`
- 监控大屏
- 展示 CPU、内存、磁盘、GPU、AI 模型状态、服务健康、今日活动、传感器趋势、操作日志

### `/docs`
- 帮助文档页
- 面向用户提供系统说明、使用方式与 FAQ

## 管理端页面

### `/admin`
- 管理仪表盘入口

### `/admin/knowledge`
- 管理 Dify 知识库
- 支持查看知识库列表、文档列表、上传文档、创建文本型文档、删除文档、语义召回测试

### `/admin/models`
- 模型管理页面
- 查看 Ollama 版本、已安装模型、运行中模型、系统利用率
- 支持拉取模型、删除模型、复制模型

### `/admin/settings`
- 系统配置管理
- 配置 Dify、Home Assistant、Ollama、InfluxDB、JWT 时长、注册开关等

### `/admin/users`
- 用户管理
- 管理用户信息、角色和启用状态

### `/admin/agents`
- 智能体管理入口
- 主要承载 Dify 应用与编排相关展示和扩展位

## 核心业务能力

### 1. AI 对话
- 流式对话
- 阻塞式对话
- 会话管理
- 停止响应

### 2. 设备控制
- 设备搜索
- 设备列表
- 单实体状态查询
- 设备控制与动作执行
- 控制后回读最新状态

### 3. 知识库管理
- 知识库创建、删除
- 文本文档导入
- 文件文档导入
- 文档列表查询
- 语义召回测试

### 4. 系统监控
- 系统资源
- AI 模型状态
- 外部服务健康
- 今日活动统计
- 传感器历史趋势
