# 智慧家居科研平台系统总览

## 项目定位
本项目是一个面向智慧家居科研与演示场景的全栈 Web 平台，用于把大语言模型、智能体编排、智能家居控制、知识库问答和监控分析整合到同一套系统中。

系统目标不是做单一聊天机器人，而是提供一套可落地的 AI + IoT 研究平台，支持：

- AI 对话与多轮会话管理
- 基于 Dify 的智能体编排
- 基于 Home Assistant 的设备状态查询与远程控制
- 基于 Dify Dataset 的知识库管理与语义检索
- 监控大屏、模型管理、系统设置、用户管理

## 当前系统组成

- 前端：Next.js 16 + React 19
- 后端：FastAPI + SQLAlchemy Async
- 业务数据库：MySQL 8
- 智能体与知识库：Dify CE
- 智能家居：Home Assistant
- 本地模型服务：Ollama
- 监控与可视化：监控大屏 + 操作日志 + 服务健康检查

## 当前真实能力
相较于早期“只做编排、不做实控”的阶段，当前项目已经具备真实业务链路：

- AI 对话通过后端代理 Dify Chatflow，支持流式 SSE 返回
- 设备控制通过后端代理 Home Assistant REST API，可查状态、可执行控制
- 知识库管理通过后端代理 Dify Dataset API，可创建知识库、上传文档、做 hit-testing
- 管理后台可查看模型、知识库、系统状态、用户信息

## 主要访问入口

- 用户端：首页、AI 对话、设备控制、电子沙盘、监控大屏、帮助文档
- 管理端：知识库、模型管理、系统设置、用户管理、智能体管理
- 后端 API 前缀：`/api/v1`
