# 云服务器一键发布

> 适用场景：本地 Mac 一条命令构建并发布到 `42.240.132.79`，云端采用 `systemd + Nginx` 跑前后端，继续复用现有 `Dify / Home Assistant / MySQL`。

---

## 目录与端口

- 远端应用根目录：`/home/ubuntu/projects/smart-home/app`
- 当前版本软链接：`/home/ubuntu/projects/smart-home/app/current`
- 版本目录：`/home/ubuntu/projects/smart-home/app/releases/<release_id>`
- 共享配置：`/home/ubuntu/projects/smart-home/app/shared`
- 对外访问：`http://42.240.132.79:8088`
- 前端监听：`127.0.0.1:3100`
- 后端监听：`127.0.0.1:8000`

---

## 首次部署前准备

先在云服务器上准备运行时配置：

```bash
mkdir -p /home/ubuntu/projects/smart-home/app/shared
cp /home/ubuntu/projects/smart-home/app/shared/backend.env.example /home/ubuntu/projects/smart-home/app/shared/backend.env
cp /home/ubuntu/projects/smart-home/app/shared/frontend.env.example /home/ubuntu/projects/smart-home/app/shared/frontend.env
```

如果 `.example` 文件还没生成，可以先执行一次发布脚本，它会把模板上传到远端并在缺失时提示。

后端最少需要填写：

- `DATABASE_URL`
- `SECRET_KEY`
- `DIFY_BASE_URL`
- `DIFY_API_KEY`
- `HA_BASE_URL`
- `HA_TOKEN`
- `CORS_ORIGINS=["http://42.240.132.79:8088"]`

前端至少保留：

```env
NODE_ENV=production
HOSTNAME=127.0.0.1
PORT=3100
NEXT_PUBLIC_API_BASE_URL=/api/v1
NEXT_PUBLIC_WS_URL=
```

## 本地发布命令

默认发布：

```bash
SMART_HOME_DEPLOY_PASSWORD='你的服务器密码' ./scripts/deploy-cloud.sh
```

带参数发布：

```bash
./scripts/deploy-cloud.sh \
  --host 42.240.132.79 \
  --user ubuntu \
  --remote-root /home/ubuntu/projects/smart-home/app \
  --public-port 8088 \
  --frontend-port 3100 \
  --backend-port 8000 \
  --password '你的服务器密码'
```

常用附加参数：

- `--skip-build`：跳过本地 `npm ci` 和 `npm run build`
- `--only-upload`：上传并解包到新 release，但不切换 `current`
- `--rollback <release_id>`：回滚到旧版本
- `--verbose`：输出更多远端日志

---

## 发布流程

脚本会自动完成这些动作：

1. 本地检查 `sshpass`、`ssh`、`scp`、`tar`、`node`、`npm`
2. 本地执行前端构建，生成 `Next.js standalone`
3. 打包前端产物、后端源码、部署模板、版本元数据
4. 上传 tarball 到远端 `/tmp`
5. 远端创建新 release 目录并解包
6. 远端安装/更新：
   - `smart-home-backend.service`
   - `smart-home-frontend.service`
   - `smart-home-app-8088` Nginx 站点
7. 切换 `current` 到新版本
8. 重启服务并做健康检查
9. 只保留最近 5 个 release

## 回滚

先查看远端已有版本：

```bash
ssh ubuntu@42.240.132.79 'find /home/ubuntu/projects/smart-home/app/releases -maxdepth 1 -mindepth 1 -type d | sort'
```

然后执行：

```bash
SMART_HOME_DEPLOY_PASSWORD='你的服务器密码' \
./scripts/deploy-cloud.sh --rollback 20260407-153000-abcd123
```

## 健康检查

发布脚本会自动检查：

- `http://127.0.0.1:8000/api/v1/system/health`
- `http://127.0.0.1:3100`
- `http://127.0.0.1:8088`

同时会额外输出：

- `Dify` 可达性
- `Home Assistant` 可达性
- `Ollama` 可达性警告
- `InfluxDB` 可达性警告

其中 `Ollama` 和 `InfluxDB` 不会阻塞发布。
