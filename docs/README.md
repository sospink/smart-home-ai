# 项目文档目录

## 文档索引

| 文档 | 用途 | 维护建议 |
|---|---|---|
| `docs/contract/合同技术参数与完成度对照.md` | 合同 40 项原文、实现页面、接口和验收截图依据 | 合同口径或页面命名变更后同步更新 |

## 文档维护规则

- 合同验收相关页面、菜单和文档优先使用合同原词，不用内部简称替代。
- 新增设计文档放入 `docs/design/`，部署文档放入 `docs/deploy/`，合同或验收资料放入 `docs/contract/`。
- 临时原型、截图、外部参考资料不要长期放在根目录；确认无引用后及时清理。
- 文档默认使用中文和 UTF-8 编码。
